# Research

Use this skill when a Videooo project is in the `research` phase.

Turn the topic and constraints into a compact, trustworthy Research Pack useful for teaching and visualization.

- Prefer primary or authoritative sources.
- Preserve source records for substantive claims.
- Separate facts, inference, uncertainty, and contested points.
- Find examples, misconceptions, definitions, and visual opportunities.
- Do not write the final script in this phase.
- Never invent a citation.

Output data compatible with `ResearchPack` in `@videooo/domain`.
