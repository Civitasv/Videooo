# Script

Use this skill for `draft-script` and `script-review`.

Write for speech, not an essay. Prefer one idea per sentence, build intuition before formal detail where appropriate, and attach relevant research claim IDs.

Treat user editorial feedback as authoritative. Each accepted revision creates a new version.

Do not approve implicitly. Once a script version is approved, do not mutate it. Any text change creates a new draft and returns the project to review.
