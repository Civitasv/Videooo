# Storyboard

Use only after narration has been recorded and aligned.

1. Read approved script and aligned narration.
2. Segment by semantic teaching beats, not fixed durations.
3. Give each scene one teaching goal.
4. Choose the simplest useful visual.
5. Use Remotion by default for typography, code, media, captions, and composition.
6. Use Manim when equations, vectors, geometry, algorithms, or spatial scientific relationships benefit from it.
7. Compile Scene IR with integer millisecond timing.

Do not add factual claims absent from the approved research/script. Prefer continuity over decorative motion.
